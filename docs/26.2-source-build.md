# Radio Client 26.2 source build

This is the path for turning the authorized local Minecraft 26.2 JAR into the actual
Radio Client engine.

The normal GitHub Actions deployment intentionally still uses the existing compiled
26.2 HTML. The source build is local because the official game JAR and generated
Minecraft sources are not stored in this repository.

## What the helper does

Run:

```bash
python3 scripts/build-radio-26.2.py \
  --jar /path/to/minecraft-26.2.jar \
  --setup /path/to/Eaglercraft-26.2-u1-Setup \
  --java17 /path/to/java17/bin/java \
  --java25 /path/to/java25/bin/java
```

Optional:

```bash
--node /path/to/node
--npm /path/to/npm
--workspace /path/to/temporary/workspace
--keep-workspace
```

The helper:

1. reconstructs the authenticated Eagler 26.2 workspace;
2. runs `scripts/install-radio-bridge.py` against the generated source;
3. compiles the standalone browser client;
4. places that temporary client at `ref/wispcraft-26.2.html`;
5. runs the existing Radio theme/Mod Menu build;
6. removes the generated workspace and temporary standalone HTML unless requested otherwise.

## Why this is the next step

The Radio JavaScript can only change a running 26.2 `Options` object if the Java
bridge is actually compiled into the engine. The bridge therefore has to be tested
inside a real 26.2 source build before we spend more time polishing the UI.

The public 26.2 workspace documentation describes the same broad pipeline:
legitimate local 26.2 JAR -> source/decompile -> Eagler patches -> TeaVM -> browser
client. citeturn0search0turn0search5

## Expected result

Once this build succeeds, the first live test should be **Render Distance**:

- open the Radio Mod Menu;
- change Render Distance;
- press Apply;
- confirm the running game's actual render distance changes without reloading the page.

Then we expand the bridge test to the remaining vanilla options and resource-pack/skin
settings.

## Important

Do not commit the generated Minecraft source tree or the generated standalone client
to this repository. They are local build artifacts.
